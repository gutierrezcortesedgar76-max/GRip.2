# GRip.2
This is a triple servo wrist and claw and the base of the arm for a upcoming robotics project.
# Software
The CAD software I used was Onshape since it runs on browser and uses limited resources. 
I also used feature scripts found in the app store of Onshape to make the process easier (bevel gears and gears)
# Componets
This was designed with Gobilda parts in mind like the torque servosand everything is connected with M4 screws. I will link the Onshape to view the parts.

# Assembly Guide
Note: Reference the Onshape link for help.
Tools needed: soldering iron, M4 allen key or bit, pliers
1. insert a M4 insert in the bottom of the bevel gear with the cage. When that's done, attach the bevel holder with a screw but make sure to leave space to freely rotate.
2. Use M4 inserts and out it in each 4 holes in the 2 remaining bevel gears. use 4 M4 screws for each bevel gear and attach the low profile servo hub.<img width="556" height="566" alt="Screenshot 2026-10-25 132552" src="https://github.com/user-attachments/assets/0c2fa378-f7f9-4c03-8b96-7fa3149a4861" />

3. Place the Bevel assembly in the side holes of the Bevel holder. (they don't attach and are designed to move freely)<img width="760" height="580" alt="Screenshot 2026-10-25 132403" src="https://github.com/user-attachments/assets/bd05a1e7-6d8a-43aa-8acb-2cfdc4365aec" />
4. grab the main cage, place the assembly we have so far in the middle and grab 2 servos and put them in the order as shown below<img width="697" height="753" alt="Screenshot 2026-10-25 141136" src="https://github.com/user-attachments/assets/24f93a1a-a7b7-447e-a037-84f514128c7f" />
5. screw in the servos to the cage with M4 screws and nuts (you don't need inserts for this)<img width="720" height="600" alt="Screenshot 2026-10-25 132646" src="https://github.com/user-attachments/assets/2e1555c2-e538-45b1-8644-92d80915db49" />
6. Grab the 2 bases for the claw and put them in place as shown in the picture above <img width="1130" height="782" alt="Screenshot 2026-10-25 141347" src="https://github.com/user-attachments/assets/70081d45-e41b-4364-8b6d-9cfa75849d81" />
7. Grab both TPU grippers and glue them in the tracks of the bases of the claw (also the bottom)
8. attach the final servo onto of the gripper and the driven gear will attach to one of the fingers accordingly.<img width="840" height="477" alt="Screenshot 2026-10-25 141812" src="https://github.com/user-attachments/assets/4c5bd5a3-47c9-4bcb-9ae8-7fff85424e44" />
